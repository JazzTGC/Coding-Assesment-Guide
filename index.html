3. define and constants

These lines create "nicknames" for numbers used later in the code, so instead of typing 0.05 everywhere, the code just says VAT_RATE. Easier to read, and if the value needs to change, you only change it once up here instead of hunting through the whole file.

#define VAT_RATE 0.05f #define DISCOUNT_RATE 0.10f #define DISCOUNT_THRESHOLD 60.0f #define MIN_QTY 1 #define MAX_QTY 10 #define LINE_LENGTH 32

4. Function Prototypes

The compiler reads your code from top to bottom. If main calls a function that's written further down in the file, the compiler won't know it exists yet and will throw an error. These lines just tell the compiler this function exists so it doesn't error.

void print_line(void); void print_money(float amount); void show_menu(void);

5. Other Functions (print_line)

We make another function that prints "=" 32 times (or however many you have set for the LINE_LENGTH defined earlier) so we just type in print_line(); later whenever we need that

void print_line(void) { int i; for (i = 0; i < LINE_LENGTH; i++) { printf("="); } printf("\n"); }

6. Other Functions (print_money)

Prices are floats, which can print with weird amounts of decimals if you let them. This function always prints a price the same way, with "AED" in front and exactly 2 decimal places, so the receipt looks consistent no matter what number goes in.

void print_money(float amount) { printf("AED %.2f\n", amount); }

7. Other Functions (show_menu)

This just prints the menu so the customer can see their options and numbers to pick from. The items and prices below are only a sample, swap them for whatever actually makes sense for your restaurant or kitchen, the numbers just need to match up with the choices in the switch statement later.

void show_menu(void) { printf("\n"); print_line(); printf(" QuickBite Kitchen Menu\n"); print_line(); printf(" 1. Chicken Shawarma "); print_money(18.00f); printf(" 0. Finish order\n"); print_line(); }

8. Main Function - Variables

Think of these as empty boxes the program fills in as it runs. subtotal, discount, vat, and total hold money amounts, choice and qty hold whatever numbers the customer types in, and items_ordered just counts how many items got added. They all start at 0 because nothing has happened yet.

float subtotal = 0.0f; float discount = 0.0f; float discounted = 0.0f; float vat = 0.0f; float total = 0.0f; float price = 0.0f; int choice; int qty; int items_ordered = 0;

9. Taking the Order (do/while and switch)

do/while means the code inside runs at least once, then keeps repeating until the condition at the bottom is false, here that means it keeps showing the menu until the customer types 0. The switch is just a shortcut for "if choice is 1, do this, if choice is 2, do that", matching whatever number they typed to the right price.

do { show_menu(); scanf("%d", &choice); switch (choice) { case 0: break; case 1: price = 18.00f; break; default: printf("Invalid choice.\n"); break; } } while (choice != 0);

10. Checking the Quantity

This makes sure the quantity typed in actually makes sense, between 1 and 10. If someone types 0, -5, or 500, it shows an error and does not add anything to the total, instead of silently messing up the order.

if (qty < MIN_QTY || qty > MAX_QTY) { printf("Invalid quantity. Please enter %d to %d.\n", MIN_QTY, MAX_QTY); }

11. No Items Ordered

If the customer hits 0 right away without ever picking an item, there is nothing to put on a receipt. This just catches that case, says so, and ends the program early instead of printing a receipt full of zeros.

if (items_ordered == 0) { printf("\nNo items ordered. Goodbye!\n"); return 0; }

12. Calculating Discount, VAT, and Total

First it checks if the subtotal is big enough to earn the 10 percent discount. Then it takes the discount off, adds 5 percent VAT on top of that smaller amount, and whatever is left after that is the final total the customer pays.

if (subtotal >= DISCOUNT_THRESHOLD) { discount = subtotal * DISCOUNT_RATE; } discounted = subtotal - discount; vat = discounted * VAT_RATE; total = discounted + vat;
